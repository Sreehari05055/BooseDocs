Table of Contents

Namespace BOOSEapp

Classes

AppCommandFactory

Factory class for creating BOOSE command instances based on command names. Extends the base CommandFactory to provide application-specific command creation.

BooseApp

Main form class for the BOOSE application. Handles user interface interactions, program parsing, execution, and canvas rendering.

BooseArray

Represents an array variable in the BOOSE language. Supports one-dimensional and two-dimensional arrays of integer or real types. Provides peek (read) and poke (write) operations for array element access.

BooseBoolean

Represents a boolean variable in the BOOSE language. Handles declaration, assignment, and evaluation of boolean expressions (true/false).

BooseCall

Represents a method call command in the BOOSE language. Invokes a previously defined method with specified arguments. Syntax: call methodName [arg1 arg2 ...]

BooseCanvas

Implements the ICanvas interface to provide drawing functionality for the BOOSE application. Manages a bitmap canvas with drawing operations including shapes, lines, and text.

BooseCircle

Command class for drawing circles on the canvas. Extends CommandOneParameter to handle circle drawing operations.

BooseClear

Command class for clearing the canvas. Extends CanvasCommand to handle canvas clearing operations.

BooseDrawTo

Command class for drawing a line from the current position to specified coordinates. Extends CommandTwoParameters to handle line drawing.

BooseElse

Represents the else clause of an if-else control structure in the BOOSE language. Executes a block of code when the corresponding if condition is false.

BooseEnd

Represents the end marker for compound control structures (if, while, for, method) in the BOOSE language. Handles the logic for loop continuation and method returns.

BooseFor

Represents a for loop control structure in the BOOSE language. Executes a block of code repeatedly with a loop variable iterating from start to end value with an optional step. Syntax: for variable = start to end [step increment]

BooseIf

Represents an if conditional control structure in the BOOSE language. Executes a block of code only when a specified condition is true.

BooseInt

Represents an integer variable in the BOOSE language. Handles declaration, assignment, and evaluation of integer expressions.

BooseMethod

Represents a method (function) definition in the BOOSE language. Supports local variables, parameters, and return values. Syntax: method returnType methodName [type param1, type param2, ...]

BooseMoveto

Command class for moving the drawing position without drawing. Extends CommandTwoParameters to handle position movement.

BooseParser

Parser class for analyzing and converting BOOSE program text into executable commands. Handles variable declarations, control structures (if, while, for), arrays, methods, and drawing commands. Implements the IParser interface from the BOOSE library.

BoosePeek

Represents a peek command for reading a value from an array element in the BOOSE language. Syntax: peek targetVariable = arrayName rowIndex [columnIndex]

BoosePoke

Represents a poke command for writing a value to an array element in the BOOSE language. Syntax: poke arrayName rowIndex [columnIndex] = value

BooseReal

Represents a real (double) variable in the BOOSE language. Handles declaration, assignment, and evaluation of real number expressions.

BooseReset

Command class for resetting the drawing position to the center of the canvas. Extends CanvasCommand to handle position reset operations.

BooseTriangle

Command class for drawing triangles on the canvas. Extends CommandTwoParameters to handle triangle drawing operations.

BooseWhile

Represents a while loop control structure in the BOOSE language. Executes a block of code repeatedly while a condition remains true.

BooseWrite

Represents a write command for displaying text on the canvas in the BOOSE language. Supports expressions, variables, and string concatenation. Syntax: write "text" or write expression
